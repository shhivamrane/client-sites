# Client sites

Demo websites for local businesses. Each folder is one static site, deployed on Netlify.

| Folder | Netlify project |
|---|---|
| `cafe/` | filterandco-demo |
| `coaching/` | ascend-academy-demo |
| `salon/` | velvetbloom-demo |

To edit a client's details, change the values at the top of the `<script>` block in that site's `index.html` (WhatsApp number, menu, hours).
